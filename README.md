# Pausa

为中文工作环境做的 macOS 休息提醒：开会、全屏时不打扰，到点轻轻提醒。当前阶段只给自己用。

## 你需要先看的（1 分钟）

- 设计稿：`design/pausa-v1.png`
- 三个核心决定：只做“不打扰”，不拼功能数量；短休息不全屏，长休息才全屏；自动暂停全部免费。

## 想了解原因再看（5 分钟）

- `PRD.md` 第 1、1.5、9.5 节：定位、竞争优势、视觉方向。

## 需要细节时再看

- `LAUNCH-COPY.md`：官网和首发帖草稿（暂不使用）。
