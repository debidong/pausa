## 叠放与透明度

所有图层保留完整画布，和底图左上角对齐，同尺寸缩放；不要先裁掉透明边缘。使用普通透明叠加，不要使用屏幕、相加等会额外提亮的混合方式。

从下到上：底图 → 图层 → 文字附近的柔和遮罩 → 倒计时及文案。

| 图层 | 预览采用的固定透明度 |
| --- | --- |
| 森林雾带 | 25% |
| 大海云 | 60% |
| 大海碎光 | 22% |
| 晚霞云 | 58% |
| 银河星点 | 22% |

这些透明度乘在文件已有的透明通道上。预览已按该参数合成；直接用 100% 叠加会明显偏浓。设置透明度后保持恒定，不要做忽明忽暗的动画。

## 倒计时区域与白字

设计留白区域为画面中央 40% 宽、30% 高，原始坐标 `x=1152, y=840, width=1536, height=720`。建议数字仍位于正中，辅助文案紧随其下；不要把文案延伸到下方山脊或明亮地平线。

**明亮版不能把“中央低细节”当作“裸白字在整个区域都具有足够对比度”。** 森林、大海、晚霞和银灰背景尤其需要局部文字衬底。保留风景本身的亮度，只在数字与文案后方叠一块边缘很柔和的深色椭圆遮罩，颜色可从 `#0F1823`、约 60% 峰值不透明度开始调节，并配合轻微字影。不要将整个画面盖上同样深度的黑层。

倒计时示意采用 1600×1000 画面中的椭圆中心 `(800,510)`、水平半径 260、垂直半径 140，边缘高斯模糊约 70px；文字为白色 108px 数字与 20px 辅助文案。放大到正式画布时全部乘 2.4。这是效果参考，接入时按实际字体、字号与屏幕亮度检查；不是应用已经实现的代码。

画面和透明图层本身均没有倒计时、文字、人物、Logo 或水印。预览中的英文是示意文案，不是产品文案决定。

## 动效约定

图片全部为静态 PNG，没有闪烁帧。接入默认静止也成立；如需动效，仅做缓慢、连续的小幅平移。

- 云和雾可在 90–180 秒内水平移动约 12–36 个原图像素，然后平缓反向；不要瞬间归位。
- 海面碎光建议静止；若移动，幅度控制在 8–16 个原图像素，亮度保持不变。
- 银河与星点建议静止；如需整体漂移，180 秒内不超过 12 个原图像素，不做单颗星闪烁。
- 图层不是无缝平铺纹理，不要重复拼接。边缘有元素触边，移动前需要容器裁切并在预览中检查露边。
- 系统启用减少动态效果时完全停止平移。不要做闪光、呼吸亮度、随机透明度、缩放脉冲或快速切换。

## 尺寸与清晰度说明

图像由内置 image_gen 生成；生成原图为约 1586×992，再用 Lanczos 重采样导出为精确 3840×2400。**交付尺寸符合要求，但不是原生 4K 绘制，也没有把放大描述为新增真实细节。** 纸纹和水彩边缘偏柔，接入前仍应在实际 Mac 屏幕上检查观感。原生生成尺寸与 16:10 的细微比例差通过统一导出校正。

透明图层保留原有半透明像素，没有烘焙进底图。最终放大、叠加预览与字体示意属于导出检查，正式绘画内容由 image_gen 生成。没有生成可选的夜间六成亮度版本，以免与用户最新的明亮方向混淆。

## 接入状态和下一步

交付检查已确认十张正式 PNG 均为 3840×2400，五张图层均含真实透明与半透明像素；中央安全区域的图层 alpha 最大值为 1/255，按推荐透明度叠加后可忽略。五套合成总览和森林倒计时示意已目视检查。
